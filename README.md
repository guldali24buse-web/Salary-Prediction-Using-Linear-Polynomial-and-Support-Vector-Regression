# Salary Prediction using Regression Models

## About the Project
This is a machine learning practice project that compares three different regression models to predict salaries based on education levels. The goal is to observe how different algorithms perform on the same dataset and apply necessary data preprocessing techniques.

* Data Preprocessing & Train/Test Splitting
* Feature Scaling (StandardScaler)
* Data Visualization with Matplotlib
* Model Evaluation Metrics: R-Squared ($R^2$), Adjusted $R^2$, MAE, and MAPE.
